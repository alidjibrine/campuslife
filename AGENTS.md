# Expo a change

Le projet est en **SDK 57**. Lire la documentation versionnee exacte sur
https://docs.expo.dev/versions/v57.0.0/ avant d'ecrire la moindre ligne de code Expo.
Ne jamais se fier a un exemple trouve ailleurs sans verifier la version.

Supabase : https://supabase.com/docs

## A savoir sur ce projet

- Expo Go en SDK 57 exige d'etre connecte au meme compte Expo dans le terminal
  et dans l'app. Compte utilise : `alidjibrine`. Apres un `npx expo login`,
  il faut **relancer le serveur**, sinon il reste en mode anonyme.
- Un build de developpement (EAS) supprime cette contrainte. C'est prevu au lot 7.
